###  ssh 介绍：
简单来说，SSH 就像是一把“网络钥匙”，它能让你在本地电脑上，安全、加密地远程登录并控制另一台服务器（通常是 Linux）。

### ssh 用法介绍:
```
ssh [用户名]@[服务器IP或域名] -p [端口号]
```
### ：process
```
ssh bandit0@bandit.labs.overthewire.org -p 2220
```
